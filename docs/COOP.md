# Two-player LAN co-op POC

The experimental co-op flow is available from **Cooperativo** on the main
menu. It is designed for two Meta Quest headsets on the same Wi-Fi network and
does not require a keyboard or developer console.

## Host

1. Open **Cooperativo**.
2. Select a campaign map in **Hospedar fase**.
3. Select **Hospedar** and wait for the map to load.

The host owns the campaign simulation, mission scripts, AI, and map changes.

## Join

1. Wait until the host is inside the selected map.
2. On the second headset, open **Cooperativo**.
3. Select **Atualizar** if the host is not listed yet.
4. Select the host and choose **Entrar**.

Both installations must use the same co-op build and compatible game data.
The initial POC uses LAN discovery and supports exactly two players. Spatial
colocation is not included; each headset positions the diorama independently.
