# Experimental two-player LAN co-op

The experimental co-op flow is available from **Co-op** on the main
menu. It is designed for two Meta Quest headsets on the same Wi-Fi network and
does not require a keyboard or developer console.

## Host

1. Open **Co-op**.
2. Select a campaign map in **Host a level**.
3. Choose a **Starting loadout**. **Story default** preserves the level's
   scripted inventory; the other choices give both players weapons immediately.
4. Select **Host** and wait for the map to load.

The host owns the campaign simulation, mission scripts, AI, and map changes.

## Join

1. Wait until the host is inside the selected map.
2. On the second headset, open **Co-op**.
3. Select **Refresh** if the host is not listed yet.
4. Select the host and choose **Join**.

Both installations must use the same co-op build and compatible game data.
The current alpha uses LAN discovery and supports exactly two players. Spatial
colocation is not included; each headset positions the diorama independently.
